# Pour aller plus loin

Cette formation vous a donné les fondamentaux et les bonnes pratiques. Voici les ressources pour continuer la progression.

---

## 📚 Ressources officielles

### Documentation Microsoft

- **[Microsoft Learn — PowerShell](https://learn.microsoft.com/powershell/)** — Documentation officielle, tutoriels, référence des cmdlets.
- **[PowerShell Gallery](https://www.powershellgallery.com/)** — Le dépôt central de modules PowerShell. Explorez, installez, publiez.
- **[PowerShell sur GitHub](https://github.com/PowerShell/PowerShell)** — Code source, issues, roadmap de PowerShell 7+.

### Outils indispensables

- **[PSScriptAnalyzer](https://github.com/PowerShell/PSScriptAnalyzer)** — Le linter officiel. Intégré dans VSCode, indispensable pour maintenir la qualité du code.
- **[Pester](https://pester.dev/)** — Framework de tests unitaires pour PowerShell. Si vous écrivez du code critique, testez-le.
- **[Plaster](https://github.com/PowerShell/Plaster)** — Générateur de templates pour modules, scripts, projets. Gagnez du temps sur la structure de base.

## 🛠️ Prochaines étapes

### Thèmes à approfondir

1. **Modules** — Créer, publier, versionner. Structurer son code en modules réutilisables.
2. **Pester** — Tests unitaires, mocking, couverture de code.
3. **CI/CD** — Intégrer PowerShell dans GitHub Actions, Azure DevOps, GitLab CI.
4. **Desired State Configuration (DSC)** — Infrastructure as code, gestion de configuration.
5. **REST API** — `Invoke-RestMethod`, gestion de tokens, pagination, throttling.
6. **Classes PowerShell** — POO en PowerShell, créer des types personnalisés.

### Projets pratiques

- **Automatiser une tâche récurrente** — Backup, nettoyage, reporting. Du one-liner au module.
- **Créer un module** — Empaqueter vos fonctions, publier sur PowerShell Gallery.
- **Contribuer à l'open source** — Corrigez un bug, ajoutez une fonctionnalité, améliorez la doc d'un module que vous utilisez.

---

## 🎯 Conclusion

PowerShell est un outil vivant, en constante évolution. La communauté est active, bienveillante, et produit une quantité impressionnante de contenu de qualité.

**Le meilleur conseil** : écrivez du code, partagez-le, demandez des reviews, lisez le code des autres. C'est comme ça qu'on progresse vraiment.

Bon scripting ! 🚀
