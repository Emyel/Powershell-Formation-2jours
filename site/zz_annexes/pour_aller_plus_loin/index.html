    Pour aller plus loin

    Cette formation vous a donné les fondamentaux et les bonnes pratiques. Voici les ressources pour continuer la progression.

    📚 Ressources officielles

    Documentation Microsoft

    • Microsoft Learn — PowerShell — Documentation officielle, tutoriels, référence des cmdlets.
    • PowerShell Gallery — Le dépôt central de modules PowerShell. Explorez, installez, publiez.
    • PowerShell sur GitHub — Code source, issues, roadmap de PowerShell 7+.

    Outils indispensables

    • PSScriptAnalyzer — Le linter officiel. Intégré dans VSCode, indispensable pour maintenir la qualité du code.
    • Pester — Framework de tests unitaires pour PowerShell. Si vous écrivez du code critique, testez-le.
    • Plaster — Générateur de templates pour modules, scripts, projets. Gagnez du temps sur la structure de base.

    🎓 Formations & livres

    Livres de référence

    • "Learn PowerShell in a Month of Lunches" — Don Jones & Jeffrey Hicks
      Le classique pour débutants. Progression douce, exercices pratiques, approche pragmatique.

    • "PowerShell for Sysadmins" — Adam Bertram
      Scénarios réels, automation, déploiement. Pour ceux qui veulent passer du script ponctuel à l'infrastructure as code.

    • "The PowerShell Scripting & Toolmaking Book" — Don Jones & Jeffrey Hicks
      Niveau avancé. Modules, tests, CI/CD, packaging. Pour transformer vos scripts en outils professionnels.

    Cours en ligne

    • PowerShell.org — Forums actifs, articles, webinars, sessions gratuites.
    • PSKoans — Apprentissage interactif type "Test-Driven Learning". Idéal pour ancrer les bases par la pratique.

    🧑‍💻 Communauté & blogs

    Forums & discussions

    • r/PowerShell (Reddit) — Communauté active, questions/réponses, partage de scripts.
    • PowerShell.org Forums — Questions techniques, entraide, annonces.
    • Stack Overflow — PowerShell — Base de connaissances massive, recherchez avant de poster.

    Blogs techniques

    • PowerShell Team Blog — Annonces officielles, nouveautés, roadmap.
    • Adam the Automator — Tutoriels pragmatiques, cas d'usage réels.
    • PowerShell Explained — Kevin Marquette. Articles détaillés sur des concepts avancés.

    🛠️ Prochaines étapes

    Thèmes à approfondir

    1. Modules — Créer, publier, versionner. Structurer son code en modules réutilisables.
    2. Pester — Tests unitaires, mocking, couverture de code.
    3. CI/CD — Intégrer PowerShell dans GitHub Actions, Azure DevOps, GitLab CI.
    4. Desired State Configuration (DSC) — Infrastructure as code, gestion de configuration.
    5. REST API — Invoke-RestMethod, gestion de tokens, pagination, throttling.
    6. Classes PowerShell — POO en PowerShell, créer des types personnalisés.

    Projets pratiques

    • Automatiser une tâche récurrente — Backup, nettoyage, reporting. Du one-liner au module.
    • Créer un module — Empaqueter vos fonctions, publier sur PowerShell Gallery.
    • Contribuer à l'open source — Corrigez un bug, ajoutez une fonctionnalité, améliorez la doc d'un module que vous utilisez.

    🎯 Conclusion

    PowerShell est un outil vivant, en constante évolution. La communauté est active, bienveillante, et produit une quantité impressionnante de contenu de qualité.

    Le meilleur conseil : écrivez du code, partagez-le, demandez des reviews, lisez le code des autres. C'est comme ça qu'on progresse vraiment.

    Bon scripting ! 🚀
